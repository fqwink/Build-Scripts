# Adlaire CI — Phase 11 仕様詳細

[`docs/details/phase11.md`](phase11.md) Phase 11 仕様詳細責務は、Phase 11 バグ修正ゼロ化に限定した source-code audit、全標準実装 artifact の横断 owner 割当、acceptance gate、差し戻し条件、完了時の未残条件を管理する。Phase 11 の現在状態、依存 Phase、active Phase は [`docs/ROADMAP.md`](../ROADMAP.md) 状態・計画責務、バグ修正ゼロ化の方針と禁止事項は [`docs/SPEC.md` 方針責務 §4.8](../SPEC.md#sec-4-8)、Phase 単位の完了条件は [`docs/SPEC.md` ポリシー責務 §0f](../SPEC.md#policy-phase-unit) を正本とする。

[`docs/details/phase11.md`](phase11.md) Phase 11 仕様詳細責務は、owner component 固有の実装契約、fixture manifest の一般形式、実装検証証跡の記録形式、または現在状態を再定義しない。owner component 固有の実装契約は各 [`docs/details/*.md`](./) 詳細本文責務、fixture / expected / fake / 実装検証証跡の一般形式は [`docs/details/fixture.md`](fixture.md) fixture 証跡責務、現在状態は [`docs/ROADMAP.md`](../ROADMAP.md) 状態・計画責務を参照する。
